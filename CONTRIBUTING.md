# Como contribuir

O repositório é um portfólio, mas o fluxo imita um time pequeno.

1. Abra uma issue com o problema e três critérios de aceite.
2. Crie uma branch curta a partir de `main`.
3. Abra um pull request usando o template. A descrição diz o problema e como testar.
4. O CI precisa ficar verde: lint, testes e build da API e do painel.

Não suba `.env`. Segredos de desenvolvimento ficam só no `.env.example`.
